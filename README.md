A real-time **Agricultural Rover Telemetry Dashboard & Field Path Tracing Web Application**. Designed to ingest live GPS coordinates, environmental sensor telemetry (soil moisture, temperature, humidity), and render path vectors over interactive maps using Leaflet.js and OpenStreetMap.

---

## ⚡ Key Capabilities

- **Live GPS Trajectory Tracing**: Real-time vector path tracking over agricultural field coordinates with waypoint logging.
- **Sensor Telemetry Gauges**: Real-time telemetry monitoring for soil moisture, ambient humidity, temperature, and battery voltage.
- **Threshold Alerting**: Visual warning states when sensor readings exceed critical crop health boundaries.
- **Zero-Backend Edge Hosting**: Pre-configured for instantaneous edge deployment on Vercel (`vercel.json`).
